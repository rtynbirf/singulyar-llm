# singulyar-llm — локальная модель СИНГУЛЯРА

Веса + инструкционный слой для голосового управления СИНГУЛЯРОМ RUVSON.
Модель живёт у человека в браузере (wllama / llama.cpp → WebAssembly),
данные не покидают устройство.

## Состав

| Путь | Что это |
|------|---------|
| `MODELS/*.part-XX-of-06.bin` | Qwen2.5-0.5B-Instruct GGUF (q4_k_m), 6 частей ≤ 100 МБ (лимит git) |
| `ОБУЧЕНИЕ/ПРАВИЛА_СИНГУЛЯРА.txt` | системный промпт: язык, честность, границы, формат ответа |
| `ОБУЧЕНИЕ/ПРИМЕРЫ_КОМАНД.jsonl` | словарь голосовых команд роутера ·21 |
| `СБОРКА/ПРОВЕРКА_ЦЕЛОСТНОСТИ.py` | сверка SHA-256 частей и целого, опциональная склейка |
| `MANIFEST.txt` | происхождение, размеры, SHA-256, честные границы |
| `LICENSE` | Apache-2.0 (унаследована от Qwen2.5) |

## Почему частями

GitHub принимает файлы до 100 МБ. Исходный GGUF — 468,6 МБ. Части — обычные
бинарные куски: склейка в порядке 01→06 даёт байт-в-байт оригинал, что и
проверяет скрипт СБОРКИ. Браузер делает то же самое на лету: качает части
параллельно, склеивает в один Blob, отдаёт в wllama.

## Проверка целостности

```bash
python3 СБОРКА/ПРОВЕРКА_ЦЕЛОСТНОСТИ.py            # части
python3 СБОРКА/ПРОВЕРКА_ЦЕЛОСТНОСТИ.py --merge    # части + склейка + целое
```

## Честно о «обучении»

Веса не дообучались (нет GPU и корпуса — и мы не изображаем обратное).
«Обучение» здесь — инструкционный слой: правила и примеры команд в `ОБУЧЕНИЕ/`,
которые страница подкладывает модели при каждом запросе. Хочешь настоящий
fine-tune — веса Apache-2.0, бери и учи; структура репы готова принять
новую версию весов (обнови MANIFEST).

## Кто это использует

`СИНГУЛЯР_21_ОБЩЕНИЕ.html` из репы `rtynbirf/singulyar`: адаптер `llm.local`
(kind `llm`) и `input.speech` (голосовой ввод) — статусы честные, как в ядре
Adapter OS: UNAVAILABLE с причиной, пока модель не загружена; READY — после;
фолбэк — правило-слой, который исполняет команды даже без весов.
